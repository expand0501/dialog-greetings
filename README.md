# Dialog Greetings

A mod for **S.T.A.L.K.E.R. Anomaly G.A.M.M.A.** by Expand.

**[Download the latest version](https://github.com/expand0501/dialog-greetings/releases)** · [Русский](#русский)

Stalkers greet you when you start talking to them, not every time you walk past.

## Features

- Opening a dialog with a stalker makes him say one of his own greeting lines, in his voice and with subtitles.
- Optional (on by default): no more "hello" every time you walk within 3 m of a stalker.
- Optional (on by default): no "put your weapon away" / "stop" lines when you walk up with a weapon drawn.
- Optional (off by default): stalkers don't react to your raised weapon at all (no aiming at you, no stopping you); story guards keep their rules.
- Hostile, wounded and voiceless characters (traders) stay silent; companions only if you want (MCM).
- Per-stalker cooldown (default 60 s) and greeting chance in MCM.
- No replaced game scripts, no per-frame work, safe to add or remove mid-playthrough.

## Installation (Mod Organizer 2)

1. Install the zip from [Releases](https://github.com/expand0501/dialog-greetings/releases) as a new mod and enable it.
2. In game: MCM > Dialog Greetings. No new game needed.

The full manual and version history are in [`src/README_EN.txt`](src/README_EN.txt) (also inside the zip).
Changes per version: [`CHANGELOG.md`](CHANGELOG.md).

## Bug reports

Open an [issue](https://github.com/expand0501/dialog-greetings/issues) with the relevant lines from

## Русский

Мод для **S.T.A.L.K.E.R. Anomaly G.A.M.M.A.**, автор Expand.

**[Скачать последнюю версию](https://github.com/expand0501/dialog-greetings/releases)**

Сталкеры здороваются, когда вы начинаете с ними разговор, а не каждый раз, когда вы проходите мимо.

### Возможности

- При открытии диалога сталкер говорит одну из своих фраз приветствия своим голосом и с субтитрами.
- По желанию (включено по умолчанию): больше никаких "привет" каждый раз, когда вы проходите ближе 3 м от сталкера.
- По желанию (включено по умолчанию): никаких "убери оружие" / "стоять", когда вы подходите с оружием в руках.
- По желанию (выключено по умолчанию): сталкеры вообще не реагируют на оружие в руках (не целятся, не останавливают); сюжетная охрана работает как раньше.
- Враждебные, раненые и неозвученные персонажи (торговцы) молчат; компаньоны — только если включить (MCM).
- Задержка повторного приветствия для каждого сталкера (по умолчанию 60 с) и шанс приветствия в MCM.
- Не заменяет скрипты игры, ничего не делает каждый кадр, можно ставить и удалять посреди прохождения.

### Установка (Mod Organizer 2)

1. Установите zip из [Releases](https://github.com/expand0501/dialog-greetings/releases) как новый мод и включите его.
2. В игре: MCM > Приветствия в диалоге. Новая игра не нужна.

Полное описание и история версий — в [`src/README_RU.txt`](src/README_RU.txt) (кодировка Windows-1251), он же лежит
в архиве.

### Сообщить об ошибке

Создайте [issue](https://github.com/expand0501/dialog-greetings/issues), приложите нужные строки из
`Anomaly\appdata\logs\xray_*.log` (сначала включите "Отладочный лог" в MCM) и опишите, что произошло.
